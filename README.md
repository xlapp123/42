# 云朵机 v2.1

一个运行在单个 HTML 文件中的 AI 角色扮演与创作平台，模拟手机操作系统界面，内置多款应用，支持 PWA 安装，无需后端服务器。

---

## 快速开始

将 `index.html` 放在任意本地目录或静态服务器上，用浏览器打开即可。

如需 PWA 离线安装，需同目录下提供 `manifest.json` 与 `sw.js`，然后通过 HTTPS 或 localhost 访问，浏览器会出现"安装到主屏幕"提示。

## 内置应用一览

### 微信（wechat）
模拟即时通讯界面，核心功能区。支持与 AI 角色一对一聊天，可发送文字、图片、语音、贴纸、红包、位置消息，支持长按消息弹出菜单（引用、收藏、撤回、删除、复制），支持消息收藏夹。内置 AI 论坛发帖联动——角色可自动在论坛发帖并通过聊天通知用户。

### 角色（chars）
角色管理中心。可手动创建角色（填写名称、人设、开场白、头像等），也可通过导入角色卡（JSON / PNG 嵌入格式，兼容 SillyTavern 卡片格式）批量添加。每个角色拥有独立聊天设置（昵称、头像、世界书关联、气泡主题、思维链显示等），并支持查看角色专属"手机界面"。支持 AI 一键生成角色人设与世界书。

### 世界书（worldbook）
知识库/词条管理工具，用于向 AI 对话注入背景设定。每本世界书可包含多个条目，每条目有名称、关键词（触发词）和内容三个字段。支持按关键词自动注入对话系统提示，支持"全局世界书"模式（对所有角色和小说创作生效）。支持导入 SillyTavern 格式世界书 JSON，也可导出为标准 JSON。

### 云音乐（music）
音乐播放器，内置推荐、音乐馆、搜索三个标签页。搜索功能对接多个免费音源（Jamendo、iTunes、Deezer、网易云、QQ 音乐、歌曲海），可在线播放并显示专辑封面，支持切换音源来源。主页有黑胶唱片小组件。

### 小说（novel）
AI 辅助小说创作工具，分快速模式和精细模式。快速模式输入简介和字数后由 AI 自动规划大纲并逐章生成；精细模式可关联角色与世界书、手动逐章填写大纲，精细控制剧情走向。支持内置小说分类推荐与标签搜索，可在线阅读 AI 续写内容。

### 论坛（forum）
模拟社区论坛界面。AI 角色可根据设定自动发帖，用户可在帖子下回复，支持"允许 AI 自动发帖"开关。

### 美化（beauty）
外观自定义中心。可选择聊天气泡主题（共六套）、深色/浅色模式、字体风格（默认、衬线、等宽、圆体），设置全局气泡主题。

### 设置（settings）
全局配置入口，包含以下子功能：

- **API 设置**：支持 OpenAI 兼容接口、Anthropic Claude、Google Gemini 三种 API 类型，可配置自定义 Base URL、API Key、模型名称，支持多预设快速切换。
- **界面渲染**：开启后，AI 回复中的 HTML 代码块将在聊天气泡内以 iframe 沙盒渲染展示。
- **安全渲染模式**：对渲染内容进行额外过滤。
- **锁屏密码**：为应用设置 PIN 码保护。
- **数据管理**：导出/导入全部数据（JSON 格式备份），支持图片数据压缩和深度数据清理。
- **移动端控制台**：内置日志查看器，便于调试。
- **多语言**：支持简体中文、繁体中文、英文、韩文、西班牙文切换。

### AI 预设（presets）
系统提示词预设管理，可创建、编辑、切换多套 AI 人格/行为预设，与 API 配置分开管理。

### 字体（fonts）
字体风格切换管理界面。

### 小红书（xhs）
模拟图文内容浏览界面。

### 音乐工坊（musicstudio）
音乐创作辅助工具。

### 城市建造（citygame）
内置休闲小游戏。

### 界面渲染器（renderer）
正则替换规则管理器，可编写正则表达式对 AI 消息进行自定义格式处理（如加粗特定词汇、替换 HTML 标签等），支持实时测试，规则可单独启用/禁用。

### 联机中心（identity）
基于 PeerJS 的 P2P 联机功能，生成唯一身份码，用于与其他用户共享角色或同步数据。PeerJS 按需加载。

### 教程（tutorial）
内置使用指南。

## 技术架构

| 层面 | 说明 |
|------|------|
| 运行环境 | 单文件 HTML，无构建步骤，无需 Node.js |
| 样式 | 纯 CSS，CSS 变量驱动主题切换，毛玻璃 + 水彩纹理风格 |
| 脚本 | 原生 JavaScript（ES2020+），无框架 |
| 持久化 | localStorage 存储主要数据，IndexedDB（通过 Dexie.js）存储收藏与贴纸大文件 |
| PWA | Service Worker（`sw.js`）+ Web App Manifest（`manifest.json`），支持离线安装 |
| 第三方库 | pako 2.1（ZIP 解压，用于 PNG 角色卡导入）、Dexie 3（IndexedDB 封装）、PeerJS（按需加载，用于联机） |
| 字体 | Noto Sans SC（Google Fonts CDN） |
| AI 接口 | 标准 OpenAI Chat Completions 格式，兼容任意同规范的第三方代理 |

## 数据存储结构

所有数据保存在浏览器本地，清除浏览器数据会导致丢失，建议定期使用"导出全部数据"功能备份。

```
localStorage
  ├── chars          角色列表
  ├── chats          聊天记录（按角色 ID 分组）
  ├── worldbooks     世界书列表及条目
  ├── novels         小说项目
  ├── chatSettings   每个角色的聊天个性化配置
  ├── settings       全局设置（API、主题、语言等）
  ├── apiProfiles    API 预设列表
  └── forumPosts     论坛帖子

IndexedDB（Dexie）
  ├── favorites      收藏的消息
  └── stickers       自定义贴纸图片
```

## API 配置说明

在"设置 → API 设置"中填写以下信息：

- **接口类型**：OpenAI 兼容 / Anthropic Claude / Google Gemini
- **Base URL**：接口地址（例如 `https://api.openai.com`，或任意中转代理地址）
- **API Key**：对应平台的密钥
- **模型**：从下拉列表选择或手动输入模型名称

支持多套预设保存与一键切换，方便在不同模型或服务商之间快速切换。

## 隐私说明

所有数据（角色、聊天记录、世界书等）均仅保存在用户本地浏览器中，不上传至任何服务器。API Key 同样仅存储在本地 localStorage，由浏览器直接向用户配置的 AI 接口发起请求。
